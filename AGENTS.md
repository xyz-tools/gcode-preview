# Agent notes

See `CONTRIBUTING.md` for setup, checks and review standards.

## Decisions

Settled decisions with hard impact are in `docs/decisions/` (one short file
each: what, why, impact). `0000-record-decisions.md` says what counts.

- Check them before changing public API, build output, packaging or rendering setup.
- If a change goes against one, flag it rather than working around it.
- If a change has hard impact, draft a record in the same PR (format in
  `docs/decisions/README.md`). Maintainers make the final call.
