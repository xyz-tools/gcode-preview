# Agent notes

See `CONTRIBUTING.md` for setup, checks and review standards.

## Decisions

Settled architecture and public API decisions are in `docs/decisions/`
(one short file each: what, why, impact).

- Check them before changing public API, build output, packaging or rendering setup.
- If a change goes against one, flag it rather than working around it.
- When a change settles something like that, draft a record in the same PR
  (format in `docs/decisions/README.md`). Maintainers make the final call.
