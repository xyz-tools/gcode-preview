gcode-preview examples

Small, self-contained pages showing how to drive the library from your own code — loading G-code, wiring up controls, reacting to what the parser found. The demo app is where to look at what the renderer can do; these are where to look at how to talk to it. Plain HTML, no build step, no framework: the whole example is the inline <script type="module">, meant to be copy-pasted.

  • Minimal

    The smallest thing that renders: a canvas, a color, and two lines of G-code.

  • Streaming

    Pass a fetch stream to processGCodeStream and watch the model grow as it loads.

  • Layer range

    Scrub the visible layers with a slider, the way a slicer's layer view does.

  • Drag & drop

    Drop a .gcode file on the canvas — the library handles the rest.

  • Thumbnail

    The preview image and slicer name that slicers embed in G-code comments.
