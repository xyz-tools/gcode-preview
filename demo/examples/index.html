gcode-preview examples

One page per feature — plain HTML, no build step, no framework. View source on any of them: the whole example is the inline <script type="module">, so it is meant to be copy-pasted.

  • Minimal

    The smallest thing that renders: a canvas, a color, and two lines of G-code.

  • Streaming

    Pass a fetch stream to processGCodeStream and watch the model grow as it loads.

  • Build volume

    The bed grid and volume outline, and what every buildVolume field does.

  • Layer range

    Scrub the visible layers with a slider, the way a slicer's layer view does.

  • Tube geometry

    Extrusions as solid tubes with real width and height instead of flat lines.

  • Multi-color

    One color per tool, so a multi-material print renders as it was printed.

  • Arcs (G2/G3)

    Arc moves, and the tolerance that controls how finely they are tessellated.

  • Thumbnail

    The preview image and slicer name that slicers embed in G-code comments.

  • Orthographic camera

    Parallel projection for a technical top or front view, plus travel moves.

  • Drag & drop

    Drop a .gcode file on the canvas — the library handles the rest.
