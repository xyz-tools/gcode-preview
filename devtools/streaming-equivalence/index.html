Streaming Equivalence Checker

← dev tools · demo

Pick a version and a file, then hit run.
Runner

Parses the same file twice in one version — once as a whole string, once as a stream of fixed-size chunks (chunk boundaries can split lines mid-command) — then diffs the resulting stats and a triangles-rendered fingerprint. Small chunks maximize boundary-split coverage. Floats are compared rounded to 4 decimals, so legitimate float-accumulation noise in extrusion distance is not flagged. Published versions load from jsDelivr; "local build" uses dist/gcode-preview.es.js from this checkout (run npm run build first).
