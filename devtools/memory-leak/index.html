JS heap after dispose (MB), per cycle

Run the test to chart heap usage per cycle.

Each run does repeated create → load → render → dispose cycles against a fresh <canvas> (mimicking a framework remount) in one iframe, then samples the heap and the renderer's geometry/texture counters after every dispose. A healthy build holds heap flat across cycles and drives both counters to 0 on dispose — any post-dispose residual means dispose() leaked GPU resources (release gate from issue #402). Heap numbers need Chrome (performance.memory); the residual counters work in any browser. "local build" uses dist/gcode-preview.es.js from this checkout (run npm run build first).
