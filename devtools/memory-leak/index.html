JS heap after dispose (MB), per cycle

Run the test to chart heap usage per cycle.

Each run does repeated create → load → render → dispose cycles against a fresh <canvas> (mimicking a framework remount) in one iframe, then samples heap and renderer counters after every dispose. A healthy build holds heap, geometries, and textures flat across cycles (release gate from issue #402). Heap numbers need Chrome (performance.memory); geometry/texture counts work in any browser. "local build" uses dist/gcode-preview.es.js from this checkout (run npm run build first).
