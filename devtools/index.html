GCode Preview Dev Tools

← back to demo

Debugger

Step through a gcode file command by command: breakpoints, a live preview that draws as you step, and the interpreter's State object with changes highlighted. Includes parser inspection: summary stats, a command-type histogram, and a filterable virtual-scrolled command list.

Benchmark

Compare two library versions (npm or the local build) on a demo gcode file: parse time, time to first render, FPS while orbiting, peak heap.

Memory-leak tester

Repeated create → load → dispose cycles with a live heap chart and renderer.info counters; flags upward trends.

Streaming equivalence checker

Parses the same file as one string and as a chunked stream, then diffs job stats to catch chunk-boundary parser bugs.

Visual diff

Renders the same file in two versions with an identical camera and pixel-diffs the captures to catch silent rendering regressions.
