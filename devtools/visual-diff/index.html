Each version renders once in a fresh iframe, the camera is pinned to the preset's initial position with the orbit target at the origin, and the WebGL canvas is captured to a PNG immediately after the synchronous render. The diff paints unchanged pixels as dimmed grayscale of image A and changed pixels (any RGB channel off by more than the threshold) in magenta. Published versions load from jsDelivr; "local build" uses dist/gcode-preview.es.js from this checkout (run npm run build first).
