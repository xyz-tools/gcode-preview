Click a row's left gutter to toggle a breakpoint. Stepping clears the filter and shows the (unfiltered) page containing the current command.

The selected version parses the file inside an iframe with its own import map and keeps the full command list (and the debug session's job) in memory there; only summaries, 200-row pages, and state snapshots cross to this page. The iframe doubles as the live debug preview. Full inspection needs a 3.x build (2.x doesn't export the parser). "local build" uses dist/gcode-preview.es.js from this checkout (run npm run build first).
